- 用户反馈"没有成功启动"。诊断: Docker MySQL 容器一直正常 (127.0.0.1:3306, bagisto 库)，但 `php artisan serve` 后台进程在上一轮会话切换时被回收，端口 8000 无监听。
- **启动坑（已解决）**:
  1. 沙箱环境**没有 `setsid` 命令**，`nohup setsid ...` 会报 "No such file or directory" 导致启动失败。
  2. Bash 工具的 `run_in_background` 托管进程会在对话 turn 之间被清理，不能跨会话常驻。
  3. 正确做法: `nohup php artisan serve --host=0.0.0.0 --port=8000 > /tmp/bagisto-serve.log 2>&1 & disown`，让进程脱离终端由 init 收养。
